## 📖 Sobre o Projeto

O projeto **Luz Doces** nasceu da necessidade de unir a delicadeza da confeitaria artesanal com uma interface digital de alta performance. Diferente de e-commerces genéricos, este site foi construído sob medida para refletir a sofisticação da marca, utilizando uma arquitetura escalável e design focado em conversão.

### 🌟 Diferenciais
- **UI/UX Personalizada:** Paleta de cores baseada em Rosa Quartz e Castanho Gourmet.
- **Navegação Fluida:** Transições suaves entre vitrine, sacola e checkout.
- **Gestão Híbrida:** Fluxos distintos para Clientes e Administração.

## 💻 Como Iniciar o Desenvolvimento

---

```bash
# Clone este repositório
$ git clone [https://github.com/seu-usuario/doceria-da-esposa.git](https://github.com/seu-usuario/doceria-da-esposa.git)

# Acesse a pasta
$ cd doceria-da-esposa

# Instale as dependências
$ npm install

# Execute a aplicação
$ npm run dev
